대규모 언어 모델을 배포하고 에이전트를 구축하기 전에 워크샵 환경에 액세스할 수 있는지 확인합니다. 이 워크샵은 참여 방식에 따라 두 가지 방법으로 진행할 수 있습니다.

## 경로 선택

::::tabs

:::tab{label="AWS Event"}
### AWS 이벤트 참여

**인프라가 사전 배포되어 준비되어 있습니다.** 

이벤트 주최자가 이미 다음을 설정했습니다:
- 필요한 모든 컴포넌트가 있는 EKS 클러스터
- Agentic AI 플랫폼 스택 (vLLM, LiteLLM, Langfuse)
- 모델 스토리지 및 캐싱
- 네트워킹 및 보안 구성

[**AWS 이벤트 설정으로 계속 →**](/introduction/getting-started/at-aws-event/)
:::

:::tab{label="Own Account"}
### 자신의 AWS 계정 사용

개인 또는 회사 AWS 계정에서 이 워크샵을 독립적으로 실행하면 다음과 같은 이점이 있습니다:
- 환경에 대한 완전한 제어
- 워크샵 후에도 리소스 유지 가능
- 구성을 커스터마이징할 기회
- 인프라에 대한 더 깊은 이해

**필요한 사항**:
- 적절한 권한이 있는 AWS 계정
- 워크샵 인프라 배포
- EKS 클러스터에 대한 액세스 구성
- 모든 컴포넌트가 실행 중인지 확인

::alert[**비용 경고**: 이 워크샵은 GPU 및 Neuron 인스턴스를 사용하므로 요금이 발생합니다. 완료 후 반드시 리소스를 정리하십시오.]{type="warning"}

::alert[**자체 계정 설정**: 자신의 AWS 계정에서 이 워크샵을 실행하기 위한 자체 진행 설정 가이드는 곧 제공될 예정입니다. 현재 이 워크샵은 사전 프로비저닝된 인프라가 있는 AWS 이벤트에서 실행되도록 설계되었습니다.]{type="info"}
:::
